# 民宿酒店项目全套开源系统

源码地址：ym7k.com/20084/

民宿、小型酒店、特色客栈经营中常常面临房态混乱、预订分散、对账繁琐、入住登记麻烦等问题，这套民宿酒店全套开源系统围绕客房管理、在线预订、入住退房、订单财务、客诉运维、后台运营形成完整业务闭环，支持私有化部署，适合单体民宿、小院客栈、小型连锁酒店搭建独立的预订管理平台。

客房与房型管理是系统的基础模块。管理员可以创建不同房型，例如大床房、标间、亲子房、套房，录入房型面积、容纳人数、配套设施、图片以及定价信息。每一间客房拥有独立档案，实时标记状态，包含空闲、已预订、入住中、待打扫、维修停用。系统支持设置房间配套标签，如带阳台、庭院景观、可携带宠物，方便客人筛选。同时支持房态日历视图，直观查看未来一段时间的房间占用情况，避免超售。

预订下单模块打通客人预订渠道。访客可以直接在前端浏览房型、查看价格、入住与退房日期，自主提交预订订单。系统自动校验所选时段房间是否可用，计算总房费。支持设置不同的定价策略，平日价、周末价、节假日溢价灵活配置，还能设置连住优惠、限时折扣。客人下单后可在线支付定金或者全款，订单实时同步后台，管理人员第一时间收到提醒，也支持线下到店由前台代录订单。

入住、退房以及前台接待功能，适配门店日常接待。客人到店后，前台可办理入住登记，录入入住人信息，支持登记多人入住信息。系统生成入住单，记录入住时间、退房时间、房费明细。退房时一键完成结算，处理额外消费、押金退还，自动更新房间状态为待打扫。保洁人员可以在系统接收打扫任务，打扫完成后更新房间状态为可售，形成房态流转闭环。

订单台账、财务对账模块解决营收统计难题。所有预订订单、入住记录、收款流水统一归档，支持按照时间、房型、订单状态检索查询。系统自动统计营业额、入住率、订单数量、客源分布等经营数据，生成日报、月报，报表支持导出，方便财务核对资金。区分已支付、待确认、已取消、退款订单，遇到客人取消预订时，可按照预设规则自动核算退款金额。

配套服务与客群维护提升入住体验。平台可以展示民宿配套服务，比如早餐、接送、团建场地、厨具租赁等增值项目，客人下单时可一并选购。支持客人留言备注特殊需求，如高楼层、安静房间、生日布置。同时可搭建简单的评价板块，客人离店后提交入住评价，评价内容可供其他预订用户参考，方便商家收集反馈优化服务。

后台权限、审核与扩展能力保障运营稳定。系统区分超级管理员、前台、保洁、财务等角色，分配不同操作权限，前台只负责接待与订单操作，财务查看对账数据。系统支持设置预订规则，如取消政策、入住退房时间、最少入住晚数。预留扩展接口，可后续对接门禁密码下发、会员储值、小程序端、第三方渠道同步房态等功能。

整套民宿酒店系统不只是预订展示页面，集合房型房态管理、在线预订、前台入住退房、价格策略、保洁派单、财务统计、客人评价等功能。私有化部署让民宿经营者自主掌控房源、订单和客户数据，不受 OTA 平台高额抽成限制，是中小型民宿、特色客栈低成本实现自主线上预订、规范化门店管理的优选方案。
